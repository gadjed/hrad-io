MaskablePPO · L1

Параметри перед стартом

Навчання не стартує, поки не натиснеш «Запустити». Прапорці ті самі, що підуть у термінал.

PPO

Скільки кроків зібрати за цей запуск. 1 крок = 1 дія моделі, не одне оновлення ваг.

Паралельні світи. 1 = один gym worker. Більше — швидший збір, більше CPU/RAM.

Довжина ролауту PPO. Стільки кроків — потім одне оновлення політики.

Розмір мінібатча SGD всередині оновлення. Має ділити ролаут.

Крок Adam. 0.0003 типово для PPO: швидше — скаче, повільніше — стабільніше.

Без окремого eval-світу. Чекпоінти все одно пишуться кожні 10k кроків.

Світ

Тіки симуляції після виконаної дії. У design-gym майже не впливає на нагороду.

Ліміт кроків епізоду. Потім reset: знову порожня цитадель.

Прототип інтер’єру. none = лише цитадель, compact curriculum.

Ollama

Питати LLM оцінку кроку. Без галочки — лише локальний teacher. Для L1 curriculum краще вимкнути.

Кожну N-ту виконану дію. 1 = кожен крок (повільно, якщо Ollama увімкнена).

Хост Ollama. localhost = ця машина, не віддалений GPU.

Порт Ollama API (зазвичай 11434).

Completion-модель, не embedding. Використовується лише з --use-ollama.

Ваги

Продовжити latest.zip. Зніми галочку або натисни «Скинути ваги» — нова мережа.

--output models/rl_agent/L1

Куди пишуться latest.zip і чекпоінти. Resume шукає тут само.
